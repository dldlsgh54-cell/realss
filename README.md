# 릴스 스튜디오

Windows에서 원본 영상 한 개 또는 여러 개를 넣어 인스타 릴스, 틱톡, 네이버 클립용 동영상으로 편집합니다.

| 결과물 | 해상도 | 편집 방식 |
| --- | --- | --- |
| 인스타 릴스 | 1080 × 1920 | 72px 흰색 볼드, 하단 35% 위에 최대 두 줄, 결과부터 시작 |
| 틱톡 | 1080 × 1920 | 78px 흰색 볼드, 핵심 단어 노란색, 오른쪽 버튼 여백, 질문·문제부터 시작 |
| 네이버 클립 | 1080 × 1920 | 62px 정보 자막, 짧은 상단 주제 카드, 장소·가격·방법에 우선순위 |

세로 화면, 자막 위치, 구간 선택, 음원 기준을 정한 배경은 [플랫폼 분석](BENCHMARK.md)에 정리했습니다. [템플릿 샘플 이미지](template-preview.png)

## 실행

1. Python 3.12 이상과 FFmpeg 8.x 전체 빌드를 설치하고 `ffmpeg`와 `ffprobe`를 PATH에 추가합니다.
2. 이 폴더에서 `python -m pip install -r requirements.txt`를 한 번 실행합니다.
3. `run.cmd`를 열고 **프로젝트 → 추가**에서 영상 파일을 여러 개 고릅니다. 파일 목록에서 원본을 바꾸고 영상별로 좌우 반전과 자막 복원 영역을 설정할 수 있습니다.
4. 오른쪽 **플랫폼 출력**에서 원하는 플랫폼만 체크하고 **내보내기**를 누릅니다. 완료한 플랫폼 카드를 선택하면 각 완성본을 확인할 수 있고, **플레이어에서 재생**으로 소리와 함께 재생할 수 있습니다. 기본 저장 위치는 `결과물`이며, 작업별 폴더에 선택한 플랫폼마다 H.264/AAC MP4와 SRT 자막이 하나씩 저장됩니다.

## 편집 기준

- 화면에 박힌 원본 자막은 새 자막을 넣기 전에 글자 위치를 찾아 배경을 복원합니다. 같은 장면의 앞뒤 프레임을 움직임에 맞춰 사용하고, 배경이 남아 있지 않은 부분은 글자 주변 픽셀로 메웁니다. 작은 자막이나 화면 속 글자와 겹친 경우 **자막 영역 지정**에서 글자 주변을 지정할 수 있습니다.
- 원본의 자막 트랙과 음성, 효과음, 배경음은 결과물에서 제외합니다. 대본을 비우면 원본 음성은 새 나레이션 대본과 구간을 추출하는 데만 사용합니다.
- 대본을 비우면 Whisper Small로 각 원본의 한국어 발화와 시간을 읽고, 플랫폼별 도입과 말할 순서를 먼저 구성합니다. 첫 실행에는 약 484 MB 모델 다운로드가 필요합니다. 기본 대본 편집은 추임새, 반복, 장황한 문체를 다듬습니다. 여러 파일의 발화가 주제를 공유하면 해당 컷을 연결하고, 말소리가 없는 영상은 길이가 충분할 때 보조 화면으로 배치합니다.
- 소리가 없거나 새 문장으로 나레이션을 넣을 때는 대본란을 사용합니다. 직접 입력한 대본은 세 결과물에 모두 들어갑니다. 목표 길이에 들어가지 않는 경우에는 대본을 줄이거나 길이를 늘릴 수 있습니다.
- 나레이션 자막을 한 화면 최대 두 줄로 배치하며 한 줄은 한글 기준 약 9~12자입니다. 어절과 문장부호를 기준으로 줄을 나누고, 합성 음성에서 시작을 맞춥니다. 아주 짧은 자막도 약 0.76초간 표시합니다.
- 기본 BGM은 프로그램이 외부 음원·샘플 없이 합성한 연주입니다. 릴스에는 밝은 템포, 틱톡에는 더 빠른 박자, 네이버 클립에는 설명을 받쳐 주는 느린 템포를 사용합니다. 선택한 음원 파일은 세 플랫폼에서 상업 이용 권한을 가진 파일을 사용합니다. 모든 트랙은 나레이션 피크 기준 15%로 믹싱합니다.
- 온라인 신경망 음성은 나레이션 대본을 Microsoft 음성 서비스에 보냅니다. Windows 한국어 오프라인 음성을 선택하면 PC에서 음성을 합성합니다.
- 기본 자동 구도는 세로 원본을 중앙 크롭하고, 가로와 정사각형 원본은 블러 배경 위에 전체 화면을 유지합니다. 화면 구성을 직접 선택할 수도 있습니다.

### 선택 사항 · 로컬 생성형 대본

Ollama를 실행하고 PC에 설치한 모델의 이름을 `REEL_OLLAMA_MODEL` 환경 변수로 지정한 뒤 프로그램을 시작하면, 발화 문장을 로컬 모델에서 다시 다듬습니다. 설정이 없는 경우에는 기본 한국어 편집 규칙을 사용합니다. [Ollama 설정과 채팅 API](https://docs.ollama.com/api/chat)
